# Shippo ChatBot

A Twitch chatbot powered by LLaMA (via Ollama) or OpenAI that responds to !ask prompts in chat as a chaotic gamer catgirl named Shippo.

## 🌐 Live Locally

### 🔧 Setup

1. Clone the repo:
   ```bash
   git clone https://github.com/velle999/Shippo-Chat-Bot
   cd Shippo-Chat-Bot
   ```

2. ollama pull llama3


3. Run it:
   ```bash
      "start-server.bat"
   ```

4. Fill out form with info from - https://twitchtokengenerator.com/
```bash 
Enter Auth Info
```
